*Complete business model for sustainable global growth*

**3. The Tourist Problem & Solution**

**3.1 The Problem**

Ethiopian tour guides at holy sites will refer foreign tourists. If we use IP geolocation:

- Tourist is physically in Ethiopia 🇪🇹
- IP address = Ethiopia
- System shows $1.99 price ❌
- Should pay $9.99 ✅

**We lose $8.00 per tourist conversion.**

**3.2 The Solution**

| **Platform** | **Detection Method** | **How It Works** |
| --- | --- | --- |
| **Web (Stripe)** | Card issuing country | Stripe's `card.country` field returns the country where the bank issued the card |
| **iOS (App Store)** | App Store account region | User's Apple ID is tied to their home country |
| **Android (Play Store)** | Play Store account region | User's Google account is tied to their home country |

**3.3 Why This Works**

**A US tourist in Ethiopia:**

| **Method** | **Result** | **Price Shown** |
| --- | --- | --- |
| IP Geolocation | Ethiopia 🇪🇹 | $1.99 ❌ |
| Card Country (Stripe) | USA 🇺🇸 | $9.99 ✅ |
| App Store Account | USA 🇺🇸 | $9.99 ✅ |
| Play Store Account | USA 🇺🇸 | $9.99 ✅ |

**Why tourists can't game this:**

- Changing App Store/Play Store country requires:
    - Payment method from the new country
    - 12-month waiting period between changes
    - Losing access to previous purchases
- Card issuing country cannot be faked

**4. Platform-Specific Implementation**

**4.1 Web (Stripe)**

**Technical approach:**

1. Create separate Stripe Price IDs for each tier
2. During checkout, detect `card.country` from Payment Method
3. Dynamically apply correct price based on country tier

**Price IDs to create:**

- `price_pro_premium_monthly` → $9.99
- `price_pro_midrange_monthly` → $4.99
- `price_pro_emerging_monthly` → $1.99

**4.2 iOS (App Store)**

**How it works:**

- Apple uses the user's **App Store account country** (not location)
- Set different price tiers per storefront in App Store Connect
- Apple auto-converts and displays in local currency

**App Store Connect setup:**

1. Create subscription product
2. Set base price for US storefront (Tier 10 = $9.99)
3. Manually override Ethiopia storefront to Tier 2 ($1.99)
4. Override mid-range countries to appropriate tier

**Apple's regional tiers:**

| **Country** | **Price Tier** | **Local Price** |
| --- | --- | --- |
| USA | Tier 10 | $9.99 |
| UK | Tier 10 | £9.99 |
| Ethiopia | Tier 2 | ~$1.99 |
| India | Tier 2 | ₹129 (~$1.55) |

**4.3 Android (Google Play)**

**How it works:**

- Google uses the user's **Play Store account country** (not location)
- Set custom prices per country in Play Console
- Google handles currency conversion

**Play Console setup:**

1. Go to Monetize → Products → Subscriptions
2. Set base price $9.99 USD
3. Click "Edit prices" for regional overrides
4. Set Ethiopia, India, etc. to $1.99 equivalent
5. Set mid-range countries to $4.99 equivalent

**Google's regional pricing:**

| **Country** | **Set Price** | **Local Currency** |
| --- | --- | --- |
| USA | $9.99 | $9.99 USD |
| Ethiopia | $1.99 | ~100 ETB |
| India | $1.99 | ₹169 |
| Brazil | $4.99 | R$24.99 |
