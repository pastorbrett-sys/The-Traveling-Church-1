# Daily Verse Notifications - 365 Curated Verses

This document contains 365 uplifting Bible verses from the World English Bible (WEB) translation for daily push notifications.

## Themes
Each verse is categorized into one of 8 themes, rotating throughout the year for variety:
1. Hope & Promise
2. Encouragement & Strength
3. Love & Acceptance
4. Guidance & Wisdom
5. Motivation & Purpose
6. Peace & Comfort
7. Faith & Trust
8. Joy & Gratitude

## Format
Each verse includes:
- `dayOfYear`: 1-365
- `theme`: Category
- `book`, `bookId`, `chapter`, `verse`, `endVerse`
- `text`: Full WEB translation text
- `notificationText`: Short preview (under 60 characters)

## Notes for Implementation

1. All verses are from World English Bible (WEB) - Public Domain
2. Each notification text is under 60 characters for push notification preview
3. Themes rotate throughout the year for variety
4. December includes Christmas-themed verses (Days 345-365)
5. All bookIds match the helloao Bible API format used in the app
6. Verses with range (e.g., 38-39) should use `endVerse` field
